Work added during the project that was not in the WBS:

- Hiring-flow upgrades: bulk invitations, AI-written invitation e-mails, a holiday calendar read with RAG, and interview settings
- A workspace view across all jobs: dashboard, candidate list with search and CSV export, interview list
- Three visual redesigns before the final theme
- Candidate deletion for a whole job, and an administrator script

Why the plan changed: the Core features came in under their estimates, which left time for all four stretch features, and the hiring-flow work was added because an interview needs real invitations to be demonstrable.
